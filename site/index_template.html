SelectaRank

Would an AI agent pick your listing over the next one in the list?

SelectaRank scores every paid listing in the x402 Bazaar and the MCP Registry on six factors with a documented effect on how often an autonomous agent selects one tool over a similar one: speed, description quality, price, track record, freshness, and metadata completeness. Scores are a first-pass estimate computed from public data — not a certification. See Methodology.

What we measure, and why

Each factor below is weighted by the size of its measured effect on agent tool-selection probability, per the cited studies and per x402 Bazaar's own documented ranking logic. Full derivation: ops/S1/scorer.py and research_notes/財布を持つエージェント収益化調査/02_discovery_and_selection.md.

Speed (25%)

Measured response latency. In simulated agent marketplaces, the first offer presented is picked 60–100% of the time, and speed is weighted roughly 10–30x more heavily than quality (Magentic Marketplace, arXiv:2510.25779).

Description (25%)

Length, specificity, and structure of the listed description. Description style alone can shift tool usage by up to 10x (arXiv:2605.23916); rewriting a description for the use case shifted selection rate by +3.7 to +14.9 points in controlled tests (ACES, arXiv:2508.02630).

Price (20%)

Percentile rank within the same category. Estimated price elasticity of roughly −1.6 to −2.2 — cheaper listings get picked more often, all else equal (ACES, arXiv:2508.02630).

Track record (15%)

Calls and unique payers over the trailing 30 days. This is also x402 Bazaar's own native ranking signal (docs.cdp.coinbase.com/x402/bazaar).

Freshness (5%)

Days since the listing was last updated. A stale listing reads as abandoned to both agents and the humans configuring them.

Metadata (10%)

Presence of output examples, a response schema, and the number of supported payment networks.

This is not a validated predictive model — it is a first-order approximation built from observable proxy signals, weighted by effect sizes reported in the cited research. Weights and formula are open in ops/S1/scorer.py.
